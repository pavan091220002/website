Infrastructure · Observability

One gateway for every model call.

What I builtA central LLM API gateway on FastAPI and Redis that enforces per-team token rate limits and monthly budget caps. When a provider returns HTTP 429 or goes down, traffic fails over to a secondary provider with zero downtime.

What you can seeOpenTelemetry tracks model latency, error rates and organization-wide API spend in one place.

Evaluation · CI/CD

FAQ

Questions before we start.

What should I send in my first message?

A short description of the problem, the kind of data or documents involved, and what a good result would look like. I will reply with questions or a suggested next step.

Will the AI make things up?

I build systems to reduce it: answers grounded in retrieved documents, independent evaluator models, consensus scoring that flags hallucinations, and regression tests on a golden dataset.

Can you work with the models and tools I already use?

Yes, in most cases. My gateway and evaluation work is built to sit across providers, and I work with both hosted and open-source models.

How will I know the system is still working after launch?

Tracing records latency, token cost and failures at each step, and evaluation runs on every prompt or model change, so quality drops show up before users notice them.

Can you fine-tune a model on my domain?

Yes. I build LoRA fine-tuning pipelines, benchmark the result against the base model, and package the weights for efficient inference.
